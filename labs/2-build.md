## Watch first

## Your turn

1. Open `{{STARTER_FILE_AND_FUNCTION}}`. Read the contract: it takes {{INPUT_SHAPE}}, it must return {{OUTPUT_SHAPE}}.
2. Write down the simplest case it has to handle. One line.
3. Implement it. Rough and working beats clever.
4. Check yourself: `{{BUILD_CHECK_COMMAND}}`
5. Run the real thing: `{{APPLICATION_COMMAND}}`
6. Try one input you invented yourself, not one we gave you.

**Pairs:** swap who types at the halfway mark (~15 min in).

## Done when

`{{BUILD_CHECK_COMMAND}}` passes **and** you can explain your own code to the person next to you.

## Go further

- Handle the case in step 2 that you decided to ignore.
- Make it fail loudly instead of silently when input is bad.

## Stuck?

2. Look at {{RELEVANT_API_OR_EXAMPLE}} for the call you need.
3. Compare with `solution/` — but only after you've tried. Then close it and type your own version.

# Start here

## What you're building today

**{{ONE_SENTENCE_USEFUL_APPLICATION}}** with **{{QUALCOMM_TECHNOLOGY}}**.

In 90 minutes you'll run it, build a piece of it yourself, and change it to do something you care about. You'll leave with working code on your machine.

## Before you arrive (20 min, do it at home)

Follow [setup.md](setup.md) and run the readiness command. If it fails, message the host **before** the workshop — don't spend lab time installing.

## The labs

| | | Time |
|---|---|---|
| 1 | [Run it](labs/1-run.md) — get one real result and see where {{QUALCOMM_TECHNOLOGY}} fits | 15 min |
| 2 | [Build it](labs/2-build.md) — implement the missing piece yourself | 35 min |
| 3 | [Make it yours](labs/3-make-it-yours.md) — change it for your own use case | 25 min |

Work in pairs if you can: one types, the other guesses what will happen before you hit enter. Swap at each lab.

## Keep these four notes as you go

Jot them anywhere — you'll use them at the end.

1. What I built:
2. What I changed myself:
3. What surprised me / broke:
4. One thing I'd add next:

## At the end

Three volunteers demo for 60 seconds: *here's what it does → here's the line I changed → here's what still doesn't work.*

"It broke and here's why" is a great demo. Don't fake a working result.

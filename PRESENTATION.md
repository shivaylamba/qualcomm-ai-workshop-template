# Ten-minute repository walkthrough

No installation or live cloud job is needed to present this template. Keep the repository open on GitHub.

| Time | Open | Say / show |
|---|---|---|
| 0:00–1:00 | README | “One useful project, three or four labs, one to two hours.” |
| 1:00–2:00 | START-HERE | “This is the exact page attendees receive. It tells them what to build and where to begin.” |
| 2:00–4:00 | Lab 2 | Show goal, prediction, editable file, command, checkpoint, hints, next link. |
| 4:00–5:00 | Lab 3 | Explain why participants must test a failure and justify a change. |
| 5:00–6:00 | Instructor notes | Show the separate lead path: questions, timeboxes, recovery, answer key. |
| 6:00–7:00 | Worksheet | Show what learners hand back as evidence. |
| 7:00–8:00 | Example topics | Contrast a GenieX agent app with an AI Hub image-model workflow. Same teaching structure, different implementation. |
| 8:00–9:00 | AUTHORING + workshop.json | “Use this template; fill the topic, code, data, checks, and verified setup.” |
| 9:00–10:00 | Release checklist | “A template is not a completed course. We pilot the attendee path before publishing an event.” |

Closing request: ask each teammate to propose one recognizable use case, one learner decision, and one test. Assign an owner and a pilot date, not just a topic title.

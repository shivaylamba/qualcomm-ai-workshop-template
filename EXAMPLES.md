# Two filled-in examples

Topic ideas to steal — not runnable labs. You still write and test the commands.

| | GenieX: local workday copilot | AI Hub: image model on a target device |
|---|---|---|
| **They build** | Messy notes → a time-boxed plan | Classify sample images with a model prepared for a real device |
| **Lab 1 Run** | Generate one helpful result locally | Run a reference prediction |
| **Lab 2 Build** | Add one read-only tool to the agent loop | Compile a supported model for the chosen target |
| **Lab 3 Yours** | Point it at your own notes | Add your own image category and compare latency |
| **Their decision** | What may the agent do without asking? | Which accuracy/latency tradeoff is acceptable? |
| **Prework** | Supported Snapdragon machine, SDK, cached weights | Account access, supported target, safe sample images |

Start from the official docs and verify what's currently supported:
[AI Hub getting started](https://app.aihub.qualcomm.com/docs/hub/getting_started.html) · [What is GenieX](https://geniex.aihub.qualcomm.com/en/get-started/what-is-geniex)

A cloud job is not a local device run — say which one your workshop does.
